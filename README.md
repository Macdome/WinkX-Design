# WinkX-Design

从 Cloudflare Pages 生产部署及历史部署中恢复的个人作品集网站。

## 本地预览

```powershell
npm start
```

然后访问 <http://127.0.0.1:4173>。

## 项目说明

- `index.html`、`assets/`：网站入口、样式与压缩后的 JavaScript。
- `images/`、`videos/`：作品图片和视频资源。
- 当前项目是可直接运行、部署的生产构建版本，并非原始 React/Vite 源代码。
- Cloudflare Pages 项目：`macdome-portfolio`。
